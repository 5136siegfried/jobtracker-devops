◈ ① Démarrer

1

Va sur /register et crée ton compte. Chaque utilisateur a ses propres candidatures — personne d'autre ne les voit.

2

Connecte-toi. Tu arrives sur le Dashboard qui résume tout : stats de la semaine, objectif hebdo, alertes deadlines.

3

Clique ✦ Nouvelle dans la barre de navigation pour ajouter ta première candidature.

◧ ② Ajouter une candidature

Le formulaire capture tout ce qui compte pour une décision éclairée :

  • Entreprise / Poste — obligatoires
  • Deadline — déclenche les alertes ⚡ (48h) et ⚠ (dépassé)
  • Contrat / Télétravail / Salaire — pour filtrer ensuite
  • Contact recruteur — nom + email pour les relances
  • 7 critères d'évaluation notés de 1 à 5 (sliders)
  • Ressenti & notes — champ libre, visible uniquement par toi

◧ ④ Comprendre les scores

Chaque candidature est évaluée sur 6 axes (1–5). Le score global est la moyenne — visible dans la liste et sur la page détail.

  • Tech — niveau technique de l'équipe / stack perçu
  • Valeurs — ambiance, culture d'entreprise
  • Éthique — impact du produit, pratiques RH
  • Rémunération — rapport salaire / marché
  • Évolution — perspectives de progression
  • Réputation pro — valeur sur le CV, réseau

L'intérêt (7ème slider) n'entre pas dans le score global — c'est une note subjective séparée pour trier la liste.

◫ ⑤ Calendrier

1

Le calendrier affiche automatiquement les dates de candidature (✉) et les deadlines (⏰) de toutes tes candidatures.

2

Toggle ◫ Grille / ◧ Liste selon ta préférence. La vue liste montre uniquement les événements futurs.

3

Clique sur n'importe quel événement pour aller directement à la page détail de la candidature concernée.

◈ ⑥ Thèmes

Les 3 boutons ronds dans la navbar (en haut à droite) changent le thème. Le choix est sauvegardé dans ta session.

  • Cyber — dark, vert/cyan, scanlines. Pour les nuits de code.
  • Zen — blanc cassé, tons naturels, wabi-sabi. Pour les candidatures du dimanche matin.
  • Kirby — violet profond, rose / vert lime. Pour quand tu veux de la bonne humeur.

◧ ⑦ Déploiement VPS

L'app tourne dans Docker, la DB SQLite est persistée dans un volume. 

# Lancer en production
SECRET_KEY=une-cle-robuste docker compose up -d

# Nginx reverse proxy (exemple)
location / {
    proxy_pass http://localhost:8001;
    proxy_set_header Host $host;
}

# Backup DB
docker exec jobtracker sqlite3 /data/jobtracker.db .dump > backup.sql

◈ ⑧ FAQ

  • J'ai perdu mon mot de passe
    Lance depuis le dossier app/ : python -c "from app import create_app; from models import db,User; app=create_app(); app.app_context().push(); u=User.query.filter_by(username='ton_pseudo').first(); u.set_password('nouveau'); db.session.commit()"
  • Le thème ne se sauvegarde pas
    Vérifie que la colonne theme existe dans ta DB. La migration douce est automatique au démarrage, mais si tu as une vieille DB sans cette colonne, relance simplement l'app.
  • Puis-je importer mes anciennes candidatures YAML ?
    Pas encore de script d'import intégré, mais c'est simple à faire en Python avec yaml.safe_load + boucle sur le modèle Candidature.
